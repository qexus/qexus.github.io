# Работа в Manac — Saint-Georges

Независимый информационный проект **qexus lab**, посвящённый вакансиям, условиям работы и возможностям добровольной рекомендации сотрудника компании Manac в Saint-Georges (Québec, Canada).

> Сайт не принадлежит Manac и не представляет HR. Все вакансии, базовые почасовые ставки и графики были вручную сверены с официальными страницами работодателя **17 ноября 2026 года**. Доступность вакансий и условия должны проверяться перед откликом.

## Структура

- `index.html` — страницы вакансий, контакты, фото и информация о преимуществах.
- `style.css` — адаптивная верстка.
- `filter.js` — фильтрация по категории и поиск без внешних библиотек.
- `assets/` — отдельные копии брендовых иконок qexus lab.
- `tests/check.mjs` — статические проверки контента, SEO и ссылок.

## Работа и конфиденциальность

Официальные отклики ведут на Manac. Общий контакт `info@manac.com` **не** заявлен как официальный HR email. Адрес `reserout@gmail.com` — добровольная связь с сотрудником для возможной рекомендации; ни рекомендация, ни работа не гарантированы. CV не отправляются автоматически, никакие анкеты и резюме не хранятся на сайте.

## Развёртывание на GitHub Pages

Предполагаемый репозиторий: `qexus/manac`. Выставить **Settings → Pages → Deploy from a branch → main / (root)**. Публичный URL: `https://qexus.github.io/manac/`.

Проект не требует NPM, сборки или доступа к API. Корень проекта должен содержать `index.html`, `style.css`, `filter.js`, `assets/` и `tests/`. Запустить проверки локально: `node tests/check.mjs`.

Существующий `qexus.github.io/manac/` обслуживается пока пользовательским репозиторием `qexus.github.io`. **Не удалять исходные файлы до подтверждения работы нового GitHub Pages**: если URL пересекается, переключение источника нужно проверить отдельно.

## Обновление зарплат и вакансий

1. Открыть официальные объявления: https://www.manac.com/ca/fr/compagnie/carrieres
2. Сверить ставки и надбавки **по каждой должности**. Не объединять базовую зарплату с условными премиями.
3. Удалить закрытые вакансии и добавлять новые **только с прямыми действующими ссылками**.
4. Обновить количество карточек, дату проверки и тесты при изменении списка вакансий.
5. Выполнить `node tests/check.mjs` и проверить сайт на телефоне перед публикацией.

## Архитектура

Сайт намеренно не использует API и сохраняет личные данные только в почтовой переписке, если посетитель добровольно направляет письмо. Датчики и формы сбора резюме отсутствуют.
