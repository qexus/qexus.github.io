# Checklist перед переносом

Этот файл находится в исходной папке `manac/` пользовательского репозитория `qexus.github.io`. Его содержимое следует перенести в **корень** отдельного репозитория `qexus/manac`.

## Рекомендуемые шаги

1. Создать **публичный** репозиторий `qexus/manac` и инициализировать его README.
2. Скопировать `index.html`, `style.css`, `filter.js`, `assets/`, `tests/`, `README.md`, `.github/`, `.nojekyll` в корень нового репозитория.
3. Открыть Settings → Pages → Build and deployment → Source: **GitHub Actions**.
4. Дождаться успешного workflow `Verify and publish Manac` с запущенной проверкой контента.
5. Проверить `https://qexus.github.io/manac/` и исходный HTML на наличие версии из нового репозитория. Убедиться, что `/work.html` ведёт на новый сайт.
6. Только после подтверждения переноса удалить старый каталог `manac/` из `qexus/qexus.github.io`, чтобы исключить конфликт двух источников по одинаковому URL.

Важно: если адрес проекта обслуживается старой папкой, не считать это подтверждением публикации из новой репозитории. Проверять Pages deployment в Actions **нового** репозитория.
