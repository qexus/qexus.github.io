# Проверка безопасности · ноябрь 2026

Область: исходники портала, Manac, Fisheries Norway и Fisheries Canada; публикационные workflow; локальный импорт и восстановление данных. Это проверка кода и защитных тестов, а не внешний пентест инфраструктуры GitHub.

## Исправлено

- **Повреждение локального состояния через некорректную резервную копию.** До записи проверяются типы коллекций, записи предприятий/судов, карта заметок и статусов, объём и глубина структуры, опасные ключи прототипа. Невалидная копия отклоняется до изменения сохранённых данных. Добавлены проверки нормальной копии, `null`, вложенных объектов вместо строк, чрезмерных массивов и ключей прототипа.
- **Избыточные права заданий сборки.** Публикационные права Pages и OIDC остаются только у deploy. Канадский build сохраняет запись contents, необходимую существующему механизму сохранения публичного реестра. Норвежский build читает код и настройки Pages.
- **Плавающие версии GitHub Actions.** Действия закреплены полными SHA, полученными из официальных репозиториев `actions`; ежемесячные предложения обновления настроены через Dependabot.
- **Ненужные секреты ленты вакансий.** Убрана передача feed URL/token в задания публикации. Рабочая модель — еженедельный государственный реестр и официальные ссылки на текущие вакансии.
- **Изменение личного текста переводчиком.** Обработчик динамического перевода соблюдает исключения для textarea, редактируемого содержимого и `data-no-translate`, в том числе при изменении текстового узла.

## Проверено

- Сканер публичных файлов обеих Fisheries проверяет типовые секреты, запрещённые форматы, CSP и JSON вакансий; на текущем дереве — без ошибок.
- HTTPS-ссылки фильтруются по схеме и отсутствию встроенного логина/пароля; внешние ссылки имеют защиту нового окна. В 126 индексируемых страницах не найдено ссылок `_blank` без `noopener`.
- Проверки локализации подтверждают экранирование враждебного текста в тестах Академии, неизменность официальных адресов и ключей работодателей.
- Импорт и заметки остаются локальными. Нет собственного сервера аккаунтов, оплаты или автоматической отправки заявок.

## Остаточные ограничения

| Уровень | Ограничение | Следующий шаг |
|---|---|---|
| Средний | Meta-CSP на GitHub Pages не заменяет все HTTP-заголовки, включая полноценную защиту от встраивания | При смене хостинга настроить заголовки на сервере |
| Средний | В стилях остаётся `unsafe-inline`; четыре проекта делят один origin и доступ к localStorage | Постепенно вынести inline-стили; при появлении аккаунтов рассмотреть отдельные origin |
| Средний | Сканер секретов и проверки HTML не доказывают отсутствие всех XSS или утечек | Расширять тесты границ ввода при изменении импортёров и рендеринга |
| Низкий | Google Fonts и иллюстрации Pexels зависят от внешних сервисов | При необходимости автономности хранить разрешённые ресурсы локально |

На просмотренном коде не подтверждена критическая удалённая уязвимость. Это ограниченный вывод по перечисленным проверкам, а не гарантия отсутствия уязвимостей.

Рекомендации по минимальным правам и закреплению зависимостей сверены с [официальной документацией GitHub](https://docs.github.com/en/actions/reference/security/secure-use).
