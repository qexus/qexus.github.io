# qexus lab — технический аудит

Сайты: [Portal](https://qexus.github.io/) · [Fisheries Norway](https://qexus.github.io/fisheries/) · [Fisheries Canada](https://qexus.github.io/fisheries-ca/)

**Дата проверки:** ноябрь 2026. Источники: публичные страницы, исходный код GitHub, журналы GitHub Actions и выборочный браузерный контроль. Этот аудит не является полноценным penetration test, юридической экспертизой или формальным WCAG-аудитом.

## Результат

Все три сайта доступны по HTTPS. Норвежская и канадская версии автоматически публикуются GitHub Actions и обновляют государственные реестры еженедельно. Платформа без сервера и личных аккаунтов, пользовательские заметки и прогресс хранятся в localStorage браузера.

Важное различие: **автоматизируется реестр предприятий/объектов, но не снимки вакансий**. Рыбопромышленный реестр не гарантирует найм.

### Данные / происхождение

- **Norway**: в опубликованной версии 864 записи предприятий (814 из Mattilsynet + 50 справочных/локальных), 383 судовые записи (377 официальных + 6 исходных), 27 архивных объявлений/карьерных каналов. Записи могут пересекаться.
- **Canada**: 1 752 уникальных записи предприятий и объектов; 1 159 CFIA, 589 DFO BC, 37 исходных справочных/локальных записей с пересечениями; 18 архивных объявлений Job Bank. Множество объектов — не множество юридически уникальных работодателей.
- Государственные источники допускают ошибки и временную недоступность; сертификаты, цены, иммиграционные нормы требуют дополнительной актуальной проверки.

## Исправлено в ходе аудита

1. **Производительность Canada**: каталог разделён на порции по 60 карточек с кнопкой загрузки следующих; больше не строит сразу тысячи HTML-карточек на телефоне.
2. **Стабильность обучения**: фоновое завершение загрузки реестра больше не закрывает открытый курс или страницу контактов.
3. **Надёжность weekly import**: при частичном сбое CFIA/DFO BC или Mattilsynet/Fiskeridirektoratet сохраняются предыдущие записи *только неудавшегося источника*, с пометкой stale/partial.
4. **Тесты загрузки**: добавлены Python regression tests на полный и частичный сбой и проверки GitHub Actions.
5. **Достоверность**: разделены государственные и справочные/локальные записи; пользовательский CSV в Canada больше не маркируется как подтверждённый госреестр. Ограничен размер CSV в Norway.
6. **Мобильная доступность**: состояние меню теперь синхронизируется с aria-expanded; закрытая боковая панель убрана из клавиатурной навигации на телефоне, добавлена индикация фокуса и учёт reduced motion.
7. **Индексация**: удалён noindex,nofollow с открытых образовательных сайтов; добавлены canonical, описания и метаданные превью; опубликованы robots.txt и sitemap.xml.
8. **Приватность**: добавлена [страница о данных](https://qexus.github.io/privacy.html) и ссылки на неё со всех трёх сайтов.
9. **Ссылки работодателей**: выборочно проверены все 13 официальных карьерных каналов; ссылки отвечают, но не гарантируют активные вакансии.
10. **Портфолио**: описания проектов уточнены — объявления названы архивными, а обновление данных относится к реестрам.

## Оставшиеся задачи

### Приоритет P1 — ценность и достоверность

- Добавить **автоматический, законный мониторинг актуальных вакансий**: источник, ID, дата публикации, срок действия, статус, дата последней проверки, дедупликация и удаление недоступных объявлений.
- Запрашивать подтверждение правовой и морской информации у первоисточника и указывать актуальность для каждой страны/должности. Не считать опубликованные тарифы гарантированными.
- Разделить в карточках: **предприятие / объект / судно / работодатель с карьерной страницей / активная вакансия**.
- Ввести контроль качества базы: разумные минимальные/максимальные числа записей, статистику изменений между еженедельными снимками, предупреждение об аномалиях.

### Приоритет P2 — пользователи и обучение

- Добавить прямые ссылки на подходящие вакансии, фильтры по провинции/району, профессии, языку, зарплате, типу разрешения и подтверждённым требованиям.
- Превратить короткие уроки в последовательную программу с большими упражнениями, проверенными терминами, источниками, практикой и итоговой работой. Онлайн-курс не выдаёт STCW/морских квалификаций.
- Дать возможность экспортировать и восстанавливать **весь** прогресс и избранное в одном универсальном файле; проверить миграции форматов.
- Повысить читаемость: роль текста, контраст мелких меток, большие интерактивные цели и понятная навигация назад/вперёд.

### Приоритет P3 — архитектура и качество

- Перевести общий интерфейс Canada/Norway в один поддерживаемый компонентный набор (одинаковая шапка, меню, таблицы, Academy), чтобы не копировать фиксы вручную.
- Добавить автоматические браузерные тесты мобильной навигации, сортировки/поиска, квизов, резервных копий и производительности.
- Добавить проверку битых внешних карьерных ссылок без автоматических откликов и без доступа к личным данным.
- Рассмотреть pinning GitHub Actions по commit SHA и принцип минимальных разрешений для workflow, где не требуется push в репозиторий.
- Для поисковой видимости — постоянные URL важных материалов (включая обучающие модули) и серверно-подготовленный статический контент, чтобы роботам не требовалось полностью выполнять JavaScript.
- Сделать на портале описание технологий, ограничений и истории обновлений каждой разработки.

## Безопасность

Не обнаружено явных публичных форм для сбора паролей, банковских реквизитов и CV, а также встроенной отправки заявок от имени пользователя. Внешние ссылки в основном обрабатываются через escape и noreferrer/noopener; импортируемые данные отображаются в HTML через защитные функции. При этом это **не гарантия отсутствия XSS и иных уязвимостей**: содержимое динамически собирается через innerHTML, а импорт пользовательского CSV требует дальнейших автоматизированных тестов.
